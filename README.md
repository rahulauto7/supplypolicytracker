# supplypolicytracker — TariffShift

Dynamic tariff calculation & supply chain re-routing engine, built with **Apertus 1.5** for the
[Hack Apertus Online Hackathon](https://hackapertus.ch/online-hack) (Track 2B: Own Project).

The platform tracks trade-policy changes (multilingual, extracted by Apertus), calculates landed costs
with a deterministic engine, and recommends alternative suppliers, origins and routes to protect margin.

See [docs/PLAN.md](docs/PLAN.md) for the full plan: architecture, landed-cost model, data sources,
evaluation, demo script and timeline.
